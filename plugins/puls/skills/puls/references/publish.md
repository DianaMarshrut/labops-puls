# Постоянное место, ссылка и автообновление

Цель: человек настраивает всё один раз, дальше пишет одну фразу «обнови пульс» или не делает
ничего. Дашборд живёт в одном месте — тот же артефакт, та же ссылка, тот же файл.

## Постоянное место (один раз)

### Claude (claude.ai и приложение)

Проекты есть на всех тарифах, на Free — до 5 проектов.
1. Навык «puls» уже загружен («Customize» → «Skills») — он работает и в чатах проекта.
2. «Projects» в меню слева → «+ New Project» → имя «Пульс».
3. «Set project instructions» → вставь блок «Настройки пульса» (его выдаёт навык в конце
   первой сборки) и отдельной строкой ссылку вебхука, если источник — Битрикс24 →
   «Save instructions». Claude применяет инструкции ко всем чатам проекта.
   Если поля инструкций нет (в одной статье справки оно помечено как платное) — нажми «+»
   справа на странице проекта и добавь те же настройки текстом.
4. Все сборки и обновления — в одном чате этого проекта.

На тарифах Team и Enterprise выбери видимость «Keep it private», если в настройках есть ссылка
вебхука: участники проекта видят его инструкции.

### ChatGPT

Проекты есть и на Free (на Free — до 5 файлов в проекте).
1. В меню слева — «New project» → имя «Пульс».
2. Добавь в файлы проекта `chat-instruction.md`.
3. «•••» у проекта → «Project settings» → в инструкции проекта вставь блок «Настройки пульса»
   и строку со ссылкой вебхука (если Битрикс24). Если поля нет — добавь настройки вторым файлом.
4. Все сборки и обновления — в одном чате проекта.

Не приглашай коллег в этот проект, если в нём ссылка вебхука: участники с правом
редактирования видят инструкции и файлы.

### DeepSeek

Проектов и сохранённых инструкций в официальных материалах DeepSeek мы не нашли. Минимальный путь:
1. Один чат «Пульс»: первым сообщением — `chat-instruction.md` (текстом или файлом).
2. Дальше всегда возвращайся в этот же чат (он есть в истории слева) и пиши «обнови пульс».
3. Если чат потерялся — новый чат: вставь `chat-instruction.md` и блок «Настройки пульса».

### Claude Code

Плагин установлен один раз. Настройки — файл `puls-settings.md` в рабочей папке, дашборд —
файл `pulse.html` там же. Обновление — «обнови пульс» в этой папке. Если в настройках ссылка
вебхука — не отправляй эту папку никому и не выкладывай её в общий доступ.

## Где живёт дашборд

### Claude

1. Создай дашборд как артефакт в чате проекта.
2. При каждом обновлении меняй **этот же** артефакт («обнови пульс» в том же чате), а не создавай
   новый. По справке Anthropic у каждого артефакта своя ссылка, а сохранённые в нём данные
   остаются, даже когда Claude меняет артефакт.
3. Ссылка для коллег:
   - Free, Pro, Max: «Publish» → скопировать ссылку (старый тип артефактов). Её открывают без
     аккаунта Claude. У новых артефактов — кнопка «Share»: «Only you» или «Anyone with the link»
     (на Pro и Max), открыть может только человек с аккаунтом Claude;
   - Team и Enterprise: «Share & copy link» — ссылка работает только внутри организации.
4. Не снимай публикацию ради обновления: после «Unpublish» тот же артефакт опубликовать
   снова нельзя, а его сохранённые данные удаляются.

Остаётся ли опубликованная ссылка прежней после обновления — справка Anthropic прямо
не говорит. После первого «обнови пульс» открой ссылку и проверь дату сборки внизу. Если
появилась новая ссылка — перешли её коллегам один раз.

### ChatGPT

- **Plus и Pro — сайт ChatGPT (Sites, бета).** Попроси ChatGPT сделать из дашборда сайт и
  опубликовать его. По справке OpenAI публикация выкладывает текущую версию по тому же адресу,
  следующие версии публикуются туда же. На Free и Go сайтов нет; публичная публикация
  на старте недоступна в ЕС, Швейцарии и Великобритании.
- **Canvas.** По справке OpenAI в моделях GPT-5.5 canvas больше нет, на платных тарифах он
  временно остаётся в старых моделях. Если canvas открылся — поделись через кнопку на его панели.
- **Free — файл.** Отдай HTML-код, человек сохраняет его как `pulse.html` и при обновлении
  заменяет этот же файл.

### DeepSeek и другие чаты

1. Выдай HTML-код целиком, одним блоком.
2. Подскажи: создать на компьютере файл `pulse.html` (например, в Блокноте: «Сохранить как» →
   тип «Все файлы» → имя `pulse.html`), вставить код, сохранить. При обновлении — заменить
   код в этом же файле.
3. Файл открывается двойным щелчком в браузере, на телефоне — из мессенджера или почты.

## Автообновление

Предлагай первым, если оно есть. Работает только для постоянного источника (коннектор,
ссылка вебхука, ссылка на таблицу). Excel-выгрузку задача по расписанию не скачает.

| Где | Что есть | Тариф | Что проверить на первом запуске |
|---|---|---|---|
| Claude | Задача по расписанию в Cowork: «Scheduled» → «Create scheduled task»; каждый час, день, неделю, по будням | Pro, Max, Team, Enterprise | Результат каждого запуска — отдельная сессия в «Scheduled». Обновит ли задача уже опубликованную ссылку — справка не говорит, поэтому обещай свежий дашборд в «Scheduled». Открывает ли задача ссылку вебхука — проверь |
| ChatGPT | Задача по расписанию (Tasks) | По справке OpenAI — и на Free: до 3 активных задач, не чаще раза в день (справка местами противоречит себе) | Может ли задача открыть ссылку вебхука, прочитать Google Drive и обновить сайт — справка не говорит |
| DeepSeek | Нет | — | Обновление фразой «обнови пульс» в том же чате |

Артефакт Claude, подключённый к приложениям (Pro и выше), для пульса не предлагай: наш шаблон —
статичная страница с цифрами внутри, сам он данные не читает. Перечитывает ли «живой» артефакт
с коннектором данные при каждом открытии, справка Anthropic не говорит. Свежие цифры в пульсе —
только через новую сборку: «обнови пульс» или задача по расписанию.

Задача по расписанию для Claude Cowork работает на стороне Claude, даже если компьютер выключен
(кроме задач с файлами на компьютере), и может пользоваться подключёнными коннекторами и навыками.

## Предупреждение — один раз

- Опубликованную ссылку может открыть любой, у кого она есть. Не пересылай её за пределы
  компании. Если в дашборде чувствительные данные — лучше отдать файлом.
- Ссылку вебхука храни только в личном проекте или чате. Если проект общий — не клади её туда.
- Сайты Claude и ChatGPT из России без VPN могут не открываться — у коллег без VPN ссылка
  не сработает. Тогда отдай дашборд HTML-файлом: его можно переслать в мессенджере или по почте,
  он открывается в любом браузере без интернета.
