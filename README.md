# Пульс — дашборд руководителя по ссылке

Собирает главные цифры компании на одной странице: продажи, закупки, склад,
производство, финансы. Страницу можно открыть в браузере и переслать ссылкой или файлом.

## Что делает

Настраиваешь один раз — дальше пишешь одну фразу «обнови пульс» или не делаешь ничего
(задача по расписанию).

1. Помогает завести постоянное место: проект «Пульс» в Claude или ChatGPT, чат «Пульс»
   в DeepSeek, рабочую папку в Claude Code.
2. Подключает источник, начиная с постоянного подключения, — только с правами на чтение:
   - Битрикс24 — ссылкой вебхука (Claude, ChatGPT, DeepSeek, Claude Code);
   - Google Таблицы — встроенным коннектором Google Drive (Claude, ChatGPT) или ссылкой
     «читатель»;
   - МойСклад в Claude Code — через его официальный сервер подключения;
   - amoCRM, 1С и другие системы — Excel-выгрузкой. Это путь «каждый раз руками»: для каждого
     обновления нужна свежая выгрузка.
3. Помогает выбрать 3–7 главных цифр или предлагает готовый набор.
4. Собирает дашборд — HTML-страницу, которая открывается и на компьютере, и на телефоне.
5. Держит дашборд в одном месте: тот же артефакт Claude, тот же сайт ChatGPT, тот же файл
   `pulse.html`.
6. Сохраняет настройки один раз в проекте и предлагает автообновление там, где оно есть.

## Что в репозитории

| Путь | Для чего |
|---|---|
| `plugins/puls/skills/puls/` | Сам навык: `SKILL.md`, справочники `references/`, шаблон `templates/dashboard.html` |
| `dist/puls.zip` | Тот же навык в архиве — для загрузки в Claude (claude.ai и приложение) |
| `chat-instruction.md` | Весь навык одним текстом — для ChatGPT, DeepSeek и других чатов |
| `.claude-plugin/marketplace.json` | Каталог плагинов для Claude Code |
| `scripts/build.py` | Пересобирает `dist/puls.zip` и `chat-instruction.md` после правок навыка |
| `tests/` | Проверка шаблона на тестовой Excel-выгрузке и скриншоты |

## Как поставить

### Claude Code

Claude Code — программа для работы с Claude в терминале компьютера. В Claude Code набери:

```
/plugin marketplace add DianaMarshrut/labops-puls
/plugin install puls@labopsai-puls
```

В Claude Code 2.1.275 и новее можно одной командой:

```
/plugin install puls --marketplace DianaMarshrut/labops-puls
```

Если репозиторий скачан на компьютер, вместо `DianaMarshrut/labops-puls` укажи путь
к папке, например `/plugin marketplace add ~/labops-puls`.

То же из обычного терминала:

```
claude plugin marketplace add DianaMarshrut/labops-puls
claude plugin install puls@labopsai-puls
```

### Claude (claude.ai и приложение)

Навыки есть на всех тарифах: Free, Pro, Max, Team, Enterprise.

1. Включи запуск кода: «Settings» → «Capabilities» → «Code execution and file creation».
   На тарифах Team и Enterprise это и сами навыки сначала включает владелец организации:
   «Organization settings» → «Plugins & skills» → вкладка «Policy».
2. Скачай `dist/puls.zip` из этого репозитория. Распаковывать не нужно.
3. «Customize» → «Skills» → «+» → «+ Create skill» → «Upload a skill» → выбери `puls.zip`.
4. Проверь, что навык «puls» включён в списке «Customize» → «Skills».
5. «Projects» → «+ New Project» → «Пульс». В чате проекта напиши: «Хочу дашборд по продажам».
6. В конце первой сборки Claude выдаст блок «Настройки пульса» — положи его в «Set project
   instructions» этого проекта.

### ChatGPT

1. Создай проект «Пульс» (проекты есть и на Free) и добавь в его файлы `chat-instruction.md`.
2. В чате проекта напиши: «Работай по инструкции из файлов проекта. Собери пульс» — и вставь
   ссылку вебхука Битрикс24 или ссылку на Google Таблицу. Excel-выгрузка — если другого пути нет.
3. Блок «Настройки пульса» из конца первой сборки положи в инструкции проекта
   («•••» → «Project settings»).

### DeepSeek и другие чаты

1. Открой новый чат и назови его «Пульс». Первым сообщением вставь текст `chat-instruction.md`
   (или приложи файл и напиши «Работай по этой инструкции»).
2. Вставь ссылку вебхука Битрикс24 или ссылку на Google Таблицу либо загрузи Excel-выгрузку
   и напиши: «Собери пульс». Если чат не открыл ссылку — используй Excel-выгрузку.
3. Для обновления возвращайся в этот же чат.

## Один раз и каждый раз

| Где | Что делаешь один раз | Что делаешь каждый раз |
|---|---|---|
| Claude | Загружаешь навык, создаёшь проект «Пульс», подключаешь источник (коннектор Google Drive или ссылка вебхука Битрикс24), кладёшь «Настройки пульса» в инструкции проекта, публикуешь артефакт. На Pro и выше — задача по расписанию в Cowork | Пишешь «обнови пульс» в том же чате проекта. С задачей по расписанию — ничего, свежий дашборд в «Scheduled» |
| ChatGPT | Создаёшь проект «Пульс», кладёшь `chat-instruction.md` в файлы, ссылку и «Настройки пульса» — в инструкции проекта. На Plus и Pro — публикуешь сайт (Sites). По желанию — задача по расписанию (Tasks) | Пишешь «обнови пульс» в том же чате проекта. С задачей по расписанию — ничего (сначала проверь её на одном запуске) |
| DeepSeek | Заводишь чат «Пульс», вставляешь `chat-instruction.md` и ссылку, сохраняешь дашборд в файл `pulse.html` | Пишешь «обнови пульс» в том же чате и заменяешь код в `pulse.html` |

Где «каждый раз» больше одной фразы — честно:
- Источник — Excel-выгрузка (amoCRM, 1С, МойСклад вне Claude Code): каждый раз выгрузить свежий
  файл и загрузить его в чат. Расписание такой источник не обновит.
- Битрикс24 по ссылке отдаёт до 50 записей за раз. Claude Code сам дочитывает все части.
  Браузерный чат может видеть только первые 50: если записей в CRM больше, итоги будут
  неполными — нужен Claude Code или Excel-выгрузка.
- Google Таблица по ссылке «читатель»: что чат её откроет, официально не описано — проверь
  на первой сборке. Коннектор Google Drive в Claude и ChatGPT надёжнее.

Что подтверждено справкой, а что нет — в `plugins/puls/skills/puls/references/publish.md`
(раздел «Источники»).

## Безопасность

- Для ИИ — отдельный пользователь или ключ, права только на чтение и только к нужным разделам.
- Битрикс24: вебхук создаёт отдельный сотрудник с ролью «Чтение» в CRM. ИИ пользуется только
  методами чтения (`crm.deal.list`, `crm.lead.list`). Ключ внутри ссылки вебхука — это доступ
  к CRM: храни ссылку только в личном проекте, не в общем, и не пересылай. Если ссылка могла
  утечь — удали вебхук и создай новый.
- ИИ не выводит ключи и ссылки вебхука ни в ответах, ни в дашборде. Шаблон дашборда сам
  скрывает ключ, если ссылка всё же попала в данные, и ничего не загружает из интернета.
- Если система не умеет давать ключ только на чтение (например, amoCRM) — работаем через
  Excel-выгрузку.
- Публичную ссылку на дашборд видит любой, у кого она есть. Не пересылай её за пределы компании.

## Для разработчика

После правок в `plugins/puls/skills/puls/` пересобери архив и инструкцию для чатов:

Нужен Python 3.10 или новее.

```
python3 -m venv .venv && . .venv/bin/activate
pip install -r requirements-dev.txt
python3 -m playwright install chromium
python3 scripts/build.py
python3 -m pytest tests -q
python3 tests/make_sample_xlsx.py && python3 tests/build_sample_dashboard.py
python3 tests/build_edge_dashboard.py
```

`scripts/build.py` пишет `dist/puls.zip` и рядом `dist/puls.zip.txt` — список файлов архива
и контрольную сумму SHA-256.
